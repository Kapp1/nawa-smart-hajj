# 🧪 خطة التجربة الميدانية – مشروع "نَوى"

تهدف التجربة الميدانية إلى تقييم الأداء الواقعي لتقنيات "نَوى" في بيئة تشغيل حقيقية، وذلك خلال موسم العمرة (رجب 1447هـ) في نقاط مختارة من المشاعر المقدسة.

## 🎯 الأهداف:
- اختبار التكامل الفعلي بين الأجهزة والبرمجيات
- قياس استجابة النظام للزحام، الانقطاعات، والسلوكيات المتباينة
- تحليل بيانات الاستخدام لتحسين النماذج الذكية لاحقًا

## 🗺️ المواقع المستهدفة:
- منفذ قدوم (مطار جدة أو مطار المدينة)
- نقطة توزيع (منى – مزدلفة – الحرم)
- نقطة مغادرة (مطار جدة)

## 🧰 الأجهزة المستخدمة:
- Jetson Nano + OpenCV + AWS Rekognition
- BLE Beacons (Estimote)
- لاصقات NFC
- بوابة لوحة تحكم ميدانية (Dashboard Lite)

## 🧪 خطوات التنفيذ:

1. **قبل التجربة**:
   - تدريب الفريق الميداني
   - إعداد المعدات والربط
   - تسجيل المستخدمين التجريبيين

2. **أثناء التجربة**:
   - تتبع الحجاج لمدة 3 أيام متتالية
   - مراقبة بيانات الحركة والتوجيه
   - قياس معدلات الإنذار والإشعارات

3. **بعد التجربة**:
   - تحليل البيانات عبر Firebase Realtime
   - حساب KPIs
   - إصدار تقرير تقييم نهائي

## 🧮 مؤشرات الأداء (KPIs):

| المؤشر | الهدف |
|--------|--------|
| دقة التوجيه الصوتي | ≥ 95% |
| زمن استجابة الإنذار الأولي | ≤ 3 ثواني |
| نسبة الكشف عن مخالفي التأشيرة | ≥ 85% |
| رضا المستخدم النهائي (UX) | 4.5/5 |

> هذه الخطة قابلة للتكرار والتوسع في بيئات متعددة محليًا ودوليًا.
