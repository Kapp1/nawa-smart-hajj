# 🔐 ملحق الأمن السيبراني والخصوصية – مشروع نَوى

## 1. نطاق البيانات
- بيانات بيومترية (صور الوجوه)
- بيانات التأشيرات وجوازات السفر
- بيانات موقع لحظي (GPS/BLE)
- لا يتم تخزين البيانات الحساسة على الأجهزة الطرفية بشكل دائم

## 2. سيادة البيانات
- التخزين الأساسي سيتم على بنية سحابية سعودية (SDAIA G-Cloud)
- استخدام AWS Rekognition سيكون موقّتًا في Region: me-central-1
- خطة إحلال تدريجية خلال 3 سنوات باتجاه بيئة تشغيل داخلية بالكامل (On-Premises)

## 3. التشفير
- **At Rest:** AES-256 GCM على وحدات Jetson وأي تخزين مؤقت
- **In Transit:** TLS 1.3 مع Perfect Forward Secrecy
- مفاتيح التشفير مدارة عبر KMS محلي (Key Management Service)

## 4. التحكم بالوصول
- جميع العمليات تتم عبر OAuth 2.0 + JWT
- RBAC مفعل (Roles: Admin, Operator, Read-only)
- تفعيل المصادقة متعددة العوامل (MFA) للوحة التحكم

## 5. امتثال نظام حماية البيانات الشخصية (PDPL)
- أساس المعالجة: المادة 5 – "لحماية الصحة والسلامة العامة"
- يتم طلب موافقة المستخدم عبر تطبيق نَوى أو عند استخراج التأشيرة
- يتم حذف البيانات البيومترية بعد 30 يومًا من مغادرة الحاج/المعتمر

## 6. استجابة الحوادث (Incident Response)
- فريق الأمن يتبع خطة زمنية واضحة:
  - الإبلاغ خلال ≤ 6 ساعات
  - الاستجابة الأولية خلال 2 ساعة
  - التحقيق الكامل خلال 24 ساعة
- يتم إشعار مركز الأمن الوطني عند أي خرق عالي الخطورة

## 7. اختبار الاختراق
- اختبارات Red-Team سنوية تغطي OWASP IoT Top 10
- تغطية تقييم الثغرات CVSS ≥ 7.0
- سجل الاختبارات محفوظ لمدة 5 سنوات

## 8. خارطة تدفق البيانات (Data Flow)
📍 سيتم إرفاق رسم يوضح:
- إدخال البيانات ← Edge Processing ← API ← تخزين/تحليل ← حذف آمن

> هذا الملحق يخضع للمراجعة الدورية كل 6 أشهر أو حسب تغير البنية التشغيلية.
