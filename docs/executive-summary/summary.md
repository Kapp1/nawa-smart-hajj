# 🧭 الملخص التنفيذي – مشروع "نَوى"

"نَوى" هو مشروع سعودي ذكي يهدف إلى إعادة تعريف تجربة ضيوف الرحمن عبر دمج متكامل بين:
- الذكاء الاصطناعي
- الحوسبة الطرفية
- تقنيات إنترنت الأشياء
- التحليل البيومتري والسلوكي

## 🎯 الهدف
توفير بيئة آمنة وشفافة ومستدامة لتيسير رحلة الحاج والمعتمر، ابتداءً من التأشيرة، مرورًا بالتنقل والمناسك، وانتهاءً بالمغادرة.

## 💡 لماذا "نَوى"؟
- أول مشروع يتبنى التوجيه السلوكي والنيّة الدينية ضمن البنية التشغيلية للحج
- لا يتطلب استخدام الهاتف الذكي، مناسب لجميع فئات الحجاج
- يتكامل مع منصات الجوازات، التأشيرات، وإدارة الحشود
- قابل للتوسع دوليًا وتكييفه مع سيناريوهات مختلفة

## ⚙️ المرتكزات التقنية:
- تحليل الوجوه عبر AWS Rekognition
- معالجة ميدانية عبر وحدات Jetson Nano
- تتبع الحجاج عبر BLE/NFC دون الحاجة لاتصال دائم
- لوحة تحكم مركزية مدعومة بالتحليلات

## 📊 مخرجات متوقعة:
- تقليل الحجاج المخالفين بنسبة 85%
- استجابة أسرع للحوادث في المشاعر
- توجيه دقيق حسب حالة التأشيرة
- تجربة روحانية مخصصة بلغات وسلوكيات متنوعة

## 📍 الوضع الحالي:
- تم تطوير النموذج النظري
- إعداد ملف تنفيذي تقني واقتصادي
- جاهز للتطبيق التجريبي مع الجهات الرسمية

> "نَوى" ليس مجرد تطبيق، بل منصة وطنية ذات بعد سيادي تهدف إلى الريادة العالمية في إدارة الحشود.
